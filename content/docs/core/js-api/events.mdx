JS 的事件 API 是[具名事件](/docs/core/guides/events)在 JavaScript 一侧的入口，也是内建事件的出口。

```ts title="拿到 events"
const { events } = ctx;          // 推荐：监听器记在你的插件名下，卸载时自动移除
const { events } = clovernt;     // 全局的：监听器记在 CloverCore 名下
```

需要注意：

- JS 监听器的优先级固定是 `Normal`，没法指定。
- `callback` 的第二个参数 `control` 只有一个方法 `cancel()`。
- 用 `ctx.events` 注册的，插件卸载时自动移除；用全局 `clovernt.events` 注册的，要自己 `off`。

## 内建事件在 JS 里是只读的

`control.cancel()` 对内建事件**不起作用**：这是设计。

内建事件是 C++ 一侧发布的，到 JS 时只是一份 JSON 快照，取消一个已经发出去的封包或者一个已经收到的事件没有意义。

也就是说，JS 能观察它们，但没法取消，也没法改载荷。

想拦截或修改封包，要用 C++ 的[事件系统](/docs/core/guides/events)，在 Native 插件里订阅 `PacketSendEvent` / `PacketRecvEvent` 并修改封包体。

## 自定义事件

内建名字之外的任意字符串都可以当事件名，载荷是任何能转成 JSON 的值。

```ts
ctx.events.on('my-plugin:greet', (payload, control) => {
  if (payload.who === 'blocked') {
    control.cancel();
  }
});

const cancelled = ctx.events.emit('my-plugin:greet', { who: 'world' });
```

自定义事件的取消**能**起作用，前提是事件由 JS 线程同步发布：

### 载荷限制

载荷要经过 JSON，所以：

- 函数、Symbol、BigInt 会变成 `null`
- 数字是 `double`，超过 2^53 的整数会丢精度，大整数请用字符串传

C++ 一侧用 `onNamed` 收到的是载荷的 JSON 快照，不是你传的那个对象。

### 自定义事件类型

`CloverEventMap` 有一个字符串索引签名，任意事件名都能用，只是载荷类型是 `unknown`。

想要类型提示的话，用模块增强补上：

```ts
declare module '@clovernt/sdk' {
  interface CloverEventMap {
    'my-plugin:greet': { who: string };
  }
}
```

模块名就写 `@clovernt/sdk`，和你 `import type` 时用的名字一致。

## 清理

要是用 `ctx.events` 的话就不用管。

用全局 `clovernt.events` 的话，把 `on` 返回的 id 存下来，卸载时 `off`：

```ts
const ids = [clovernt.events.on('dll-load', onLoad), clovernt.events.on('dll-load', onLoadAgain)];
ctx.onUnload(() => ids.forEach((id) => clovernt.events.off(id)));
```
