CloverCore 是一个面向QQNT的插件加载框架，他提供了高层的高级API，并支持你使用C++和JavaScript两种语言编写插件。

## 有什么优点

### 随心所欲的调用Node.js / V8 API

借助[libcxx-build](https://github.com/CloverNT/libcxx-build)的 libc++ 预构建和 [qqnt-sdk](https://github.com/CloverNT/qqnt-sdk) 的 node / v8 头文件，你可以自由的通过头文件调用这些API，并且自动处理链接，无需担心ABI兼容性问题。

### 完善的 C++ ↔ JavaScript 的互作体系

通过使用[Alka](https://github.com/SingerBallad/Alka)这一声明式 C++ ↔ V8 绑定库，C++与Javascript的调用和类型可直接方便的互通，并且自动生成 TypeScript 的类型声明。

### 底层操作也要变得Modern！

对[Mortis](https://github.com/SingerBallad/Mortis)的封装，让你在C++内也能用非常现代化的设施进行内存修改/Hook，全程类型安全。

## 它的定位

CloverCore是一个类型为`raw`的插件，直接被CloverLoader加载，之后CloverCore才会加载其他类型的插件。

换句话说，CloverCore是一个夹在用户插件和最底层组件之间的胶水层，提供了一个更现代化的插件开发体验。

<Callout type="info">
  CloverCore 强制依赖 CloverLoader。  
  CloverLoader 不公开发布，请自行寻找。
</Callout>
