## 自定义加载器

`PluginLoader` 是个纯接口，实现它就能让 CloverCore 认识一种新的插件类型：

<TypeTable
  type={{
    'PluginLoader::id()': {
      type: 'virtual std::string_view（纯虚）',
      description: '加载器的标识，必须和 clover.json 里的 type 完全一致，CloverCore 靠它分发',
    },
    'PluginLoader::load(name)': {
      type: 'virtual Expected<void>（纯虚）',
      description: '加载名为 name 的插件',
    },
    'PluginLoader::unload(name)': {
      type: 'virtual Expected<void>（纯虚）',
      description: '卸载。返回 Inactive 错误会被当成"没什么可卸的"而忽略',
    },
    'PluginLoader::reload(name)': {
      type: 'virtual Expected<void>（纯虚）',
      description: '重载。CloverCore 不会替你拆成 unload 加 load',
    },
  }}
/>

```cpp title="注册一个加载器"
class MyLoader final : public Plugin::PluginLoader {
public:
    std::string_view id() const override { return "my-type"; }
    Expected<void> load(std::string_view name) override { /* ... */ return {}; }
    Expected<void> unload(std::string_view name) override { /* ... */ return {}; }
    Expected<void> reload(std::string_view name) override { /* ... */ return {}; }
};

auto result = Plugin::PluginManager::registerLoader(std::make_shared<MyLoader>());
```

自定义类型的插件在所有 native 和 js 插件加载完之后才轮到加载器处理，所以注册加载器的插件要靠 `dependencies` 排在它们前面。

JavaScript 插件也可以注册加载器，见 [JavaScript SDK](/docs/core/js-api)。
