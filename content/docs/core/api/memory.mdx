### 创建 Hook

`Sig` 是目标函数的签名，必须是自由函数签名（不是成员函数）。

`Detour` 是可调用对象，签名是 `R(OriginalFunction<Sig>&, Args...)`，可以带捕获。

每种签名最多同时有 64 个 Hook，装不下会返回 `NoFreeSlots`。
