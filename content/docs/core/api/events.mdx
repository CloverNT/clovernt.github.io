怎么用请参阅[事件系统](/docs/core/guides/events)。

```cpp title="引入"
#include <CloverNT/API/Events/EventBus.hpp>
#include <CloverNT/API/Events/NamedEventApi.hpp>
```

## EventPriority

数值越大越先执行：

<TypeTable
  type={{
    Monitor: { type: '5', description: '最先执行，约定上只观察不修改' },
    Highest: { type: '4' },
    High: { type: '3' },
    Normal: { type: '2', description: '默认值' },
    Low: { type: '1' },

  }}
/>

同一级内按监听器 id 升序，也就是先创建的先执行。

## NamedEvent

运行时按字符串匹配、载荷是 JSON 的事件，继承了 `Event` 和 `Cancellable`。

它是 C++ 和 JavaScript 互通的桥。
